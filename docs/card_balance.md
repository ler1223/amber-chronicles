# Баланс карт: общие правила

Зафиксировано по квизу с автором. Эти правила действуют до следующего пересмотра.

## Стоимость

Минимум **1** для обычных карт.

`0` разрешён только для:
- созданных карт и токенов: `arrow`, `arrow_blood`, `t_knife`, `t_spark`;
- свитков Жреца `sc_*` — у него энергия 0, это классовый ресурс;
- редких реакций R3+: `m_ambush`, `m_counter`, `m_trophy`;
- утверждённых исключений:
  - `h_backstep`;
  - `h_knife`;
  - `h_second_wind`;
  - `p_cool`;
  - `p_czn_unity`;
  - `p_stoke`;
  - `m_battle_plan`;
  - `n_czn_adagio`.

Подняты до 1:
- `m_run`;
- `brace`;
- `h_chain_draw`;
- `h_rng_guilty`;
- `m_bloodpact`.

`h_rng_guilty` дополнительно ослаблена: **взять 2 карты**, а не 3.

## Альтернативное применение

Это особенность карты, а не стандарт.

Альтернатива сохраняется только у:
- базовых карт: `strike`, `defend`, `h_shot`, `h_dodge`, `p_bolt`, `p_ward`, `p_stride`;
- `charge` — «Натиск»;
- `body_slam` — «Удар телом»;
- `riposte` — «Ответный удар».

У `h_backstep` и `m_run` альтернатива убрана отдельным решением, хотя они базовые.

У остальных карт — только основной режим. Новые карты по умолчанию создаются **без альтернативы**; alt добавляется только после отдельного аудита.

## Адажио

`n_czn_adagio`:

- цена 0;
- альтернативы нет;
- основное: **взять 2 карты, затем сбросить 2 карты с выбором игрока**;
- сброс выбирается в бою кликом по картам; случайный сброс не используется.

## Новые боевые механики Охотницы

- **Линия** (`line`): цель только по горизонтали/вертикали, без диагоналей.
- **Пробитие** (`pierce`): выстрел по линии задевает всех врагов на пути до стены.
- **Рост в руке** (`grow_end`): карта с `retain` получает указанный бонус к урону
  в конце каждого хода, пока остаётся в руке.
- **X-цена** (`x_cost`): карта требует всю доступную энергию (минимум 1) и масштабирует
  урон через `×X` в описании.
- **Двойной залп** (`double_attacks`): первые N карт типа `attack` наносят двойной урон;
  заряд расходуется на карту, а не на отдельное попадание.

## Порядок генерации

Балансный пакет применяется после всех генераторов карт:

```text
python tools/descent_tiers.py
python tools/card_balance_policy.py
```

Если генератор карт запускается повторно, `card_balance_policy.py` нужно запустить снова, чтобы вернуть единые правила стоимости и альтернатив.

## Аудит новых карт

Перед добавлением карты согласуем:

1. роль в колоде;
2. уникальность эффекта;
3. стоимость и редкость;
4. теги;
5. взаимодействия;
6. наличие alt — по умолчанию нет;
7. пять прозрений;
8. влияние на стартовую колоду, награды и существующие архетипы.
