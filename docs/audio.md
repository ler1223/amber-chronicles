# Музыка и звук

## Треки

В игре — набор фэнтезийных треков для разных локаций. Все они **CC0 1.0 Universal (Public Domain)**
с OpenGameArt.org; авторы и ссылки — в `assets/audio/README.md`.

| Локация | Треки |
|---|---|
| Меню, выбор героя | Mythica, Doodle menu like song |
| Болото | Forest Ambience, Alone |
| Подземелье | Dungeon Ambience, Narrow Corridors, Cave explorer |
| Кузни | Through the Portal, Crystal Cave |
| Бой | Battle Theme A, Random Battle |
| Босс | Battle Theme A, war, Random Battle |
| Костёр, награды | The Great Grog, Forest Ambience |
| Магазин | The Great Grog, Doodle menu like song |
| Финал | Alone |

При смене локации включается подходящий трек; при возвращении в ту же локацию выбирается другой
из её набора. Если в системе нет аудиоустройства или mixer не инициализировался, игра продолжает
работать без звука.

## Управление

### «Спуск»

- **F10** — открыть/закрыть панель звука в любом экране: выбор героя, карта, бой, награда, магазин;
- **← / →** или **− / +** — громкость в панели с шагом **1%**;
- **M** — выключить/включить музыку;
- **Esc** — закрыть панель;
- в меню выбора героя и на карте этажа есть кнопка «Звук · F10»;
- клик по полосе громкости сразу ставит выбранный процент.

### «Хроники янтаря»

- **Ctrl+F10** — выключить/включить музыку;
- **Ctrl+− / Ctrl++** или **Ctrl+[ / ]** — громкость с шагом 1%;
- в общем меню «Настройки» есть ползунок «Громкость музыки» (точность 1%) и строка «Фоновая музыка».

Ctrl нужен потому, что обычные F10, [ и ] в бою уже заняты подсказкой и скоростью боя.

Настройки сохраняются в `save/settings.json` и переживают перезапуск.

## Код

- `ui/audio.py` — запуск/остановка музыки, громкость, горячие клавиши;
- `ui/settings.py` — сохранённые настройки;
- `deck/sound.py` — панель звука «Спуска» (F10);
- `descent.py`, `main.py` — запуск музыки;
- `game/title_scene.py` — применение звука из общего меню настроек.
