# «Спуск»: теги, условия, прозрения 2.0 и дары богов

## Решения (квизы 2026-11-19)

- **Всё держится на условиях в самих картах.** Выполнил условие — карта работает или становится сильнее.
  Пример пользователя: «сыграно 5 карт за ход — открывается возможность сыграть карту».
- **Только теги, без «семейств».** Тегов у карты несколько, большинство выводятся из её действий. Условия
  ссылаются на теги или на позицию на поле.
- **Прозрения — как эпифании CZN.** У карты 5 вариантов, при прозрении предлагаются 3 случайных, берётся один.
  Прозрение одно на карту.
- **Дар бога (божественное прозрение)** — поверх любой подходящей карты, одно на карту. Даёт его алтарь на
  карте этажа или победа над стражем лестницы.
- **Прокачка никогда не удешевляет карту.** Дешёвый ход — дело простого применения.

Справка о CZN (по фанатским гайдам): применённая карта получает эпифанию — из 5 типов улучшений предлагают 3.
Редкая «божественная» эпифания сильнее обычной, у неё свой значок.

## 1. Теги

Теги выводятся из основного применения карты; у карт с уровнями — из всех уровней. Код:
`deck/model.py: use_tags / card_tags`. Вручную можно добавить поле `"tags"`.

| Тег | Откуда берётся |
|---|---|
| Огонь | горение, поджог, вспышка, жар, «всем горящим» |
| Удар | урон вплотную: дальность 1, подход, по соседям |
| Выстрел | дальний урон (`ranged`) |
| Шаг | шаг, рывок, подход, отскок |
| Защита | защита |
| Толчок | толчок, притягивание, «столкновения ×2» |
| Метка | метка |
| Яд | яд |
| Ловушка | капкан, корни |
| Комбо | серия карт за ход, `series` / `first` / `allin` |
| Повтор | дополнительный удар или повтор при `resonance` |

Теги печатаются на карте под названием (голубым), а в бою учитываются у руки:
«Ход: сыграно 3 · Удар 2 · Шаг 1 · пройдено 4».

## 2. Условия

Выполненное условие подсвечивается на карте зелёным, у карты зелёная кайма. Код: `Battle.met` и `Battle.lit`.

**Ритм хода:**

| Условие | Когда выполнено |
|---|---|
| Серия N | за ход уже сыграно N карт основным (простое не считается) |
| Вслед за [Тег] | предыдущая карта, сыгранная основным, — с этим тегом |
| Резонанс Тег N | за ход сыграно основным N карт с этим тегом |
| Первая | это первая карта хода |
| Ва-банк | после розыгрыша не осталось энергии (у Пиромантки — жара) |

**Позиция:**

| Условие | Когда выполнено |
|---|---|
| Вплотную | цель рядом с вами |
| Издалека N | цель не ближе N клеток |
| С разбега N | за ход вы прошли ≥ N клеток |
| У стены | за целью стена, край или юнит |
| В окружении | рядом с вами ≥ 2 врагов |
| Из укрытия | рядом с вами укрытие |

**Цель:**

| Условие | Когда выполнено |
|---|---|
| По горящему, мокрому, отравленному, помеченному | на цели это состояние |
| По раненому | у цели меньше половины HP |

`per` для метки: `{"what": "mark", "k": N}` — прибавка за каждый стак метки на цели.

**Резонанс** — тег, а не отдельный эффект. Если условие `resonance` выполнено, карта при розыгрыше
повторяется ещё раз целиком. `do`, `plus` и `mult` у такого условия не применяются.

**Цепочка** — отдельный тег автоматического розыгрыша. Карта с `chain` сама играется из руки, когда
выполнено её условие (раз за ход), без оплаты. `echo`-резонанс переведён в `chain`; при ручном
розыгрыше карта просто играется один раз.

На карте условие пишется коротко: `Резонанс Выстрел 2`, без повторного описания тега. Когда Цепочка
играет карту сама, экран показывает её крупно с подписью «Цепочка · играет сама · бесплатно», затем
даёт эффекту отыграть и держит паузу перед следующей картой. Разыгранная так карта уходит в Used
(как и обычная played-карта), не возвращается в руку до конца хода и только в конце хода попадает
в сброс. Полная схема колод — `docs/descent_deck_piles.md`.

### Предметы тегов

У предметов есть `tag_bonus`: пассивная прибавка картам с тегом. Примеры:
`[Выстрел] +2 урона`, `[Удар] +2 урона`, `[Защита] +2 защиты`, `[Метка] +3 урона`,
`[Резонанс]/[Цепочка] +3 урона`. Предметы с `on: play` и `tag` дают карте тега ещё и свойство:
метку, горение, фокус, энергию.

### Что даёт выполненное условие (все четыре — в первой волне)

| Вид | Поле в данных | Что делает |
|---|---|---|
| Усиление | `main.if: [{when, plus / mult / do / repeat}]` | «Вплотную: ещё +3», «У стены: урон ×2», «В окружении: защита 4» |
| Печать | `main.seal: {условие}` | основным не сыграть, пока условие не выполнено; простое — всегда |
| Отклик | `echo: {when, do, aim}` (свойство карты) | карта в руке срабатывает сама и бесплатно, раз за ход; остаётся в руке |
| Задел | `keep: {условие}` (свойство карты) | если к концу хода условие выполнено, карта остаётся в руке |

### Новые карты-примеры (в наградах)

| Герой | Карта | Что делает |
|---|---|---|
| Наёмник | Шквал | Печать (Серия 2): 4 урона ×3 |
| Наёмник | Добить о стену | 6 урона, толчок 1; У стены: урон ×2 |
| Охотница | Последняя стрела | Печать (Резонанс Выстрел 2): дальность 7, 15 урона |
| Охотница | Ложный след | шаг 2, защита 3; Отклик (Резонанс Выстрел 2): 4 урона ближайшему |
| Пиромантка | Пожар | Печать (Резонанс Огонь 2): всем горящим +2/+3/+5 горения |
| Пиромантка | Тлеющий уголь | 4/8 урона и горение; Задел (Ва-банк) |

## 3. Прозрения 2.0

5 вариантов у каждой карты. Первая волна сгенерирована по правилам из тегов (в `cards.json`, `growth[0]`);
дальше их можно править руками.

1. **Острее / Крепче / Дальше** — числа больше (или шаг +1).
2. **Условие по теме тега:**
   - Огонь — По горящему +4;
   - Выстрел — Издалека 5 +3;
   - Удар — Вслед за [Шаг];
   - Толчок — У стены;
   - Защита — В окружении;
   - Шаг — С разбега 3: взять карту.
3. **В серии** — Серия 2: ещё урона (или взять карту).
4. **Мост** — действие с другим тегом: толчок, метка, шипы, защита.
5. **Отклик** у атак (Резонанс своего тега 2: 3 урона ближайшему) или **Задел** (Серия 3) у остальных.

Цена и жар уровней в вариантах не меняются — это проверяет тест.

## 4. Дары богов

Данные — `data/deck/gods.json`. Алтарь — новый узел карты этажа (не в первых двух рядах). Страж лестницы после
награды тоже предлагает дар. Механика одна: два бога на выбор, затем карта под дар, на карте — флажок
с буквой бога.

| Бог | Дар |
|---|---|
| Горн, бог кузни | карта даёт ещё 4 защиты |
| Пепельная, богиня огня | цель загорается: горение 2 (карте нужна цель) |
| Тропа, бог дорог | шаг, подход и дальность карты +1 |
| Близнец, бог повторов | Серия 2: карта срабатывает дважды |
| Тень, богиня хитрости | цель получает метку 3 (карте нужна цель) |

## 5. Стрелки (2026-11-19)

Стоят и стреляют на 5 клеток по линии обзора, зона обстрела подсвечена. Вне зоны только перебегают. Первый
ход — «Прицел»: занять позицию и прицелиться.

## Дальше

- Ручная полировка вариантов прозрений по картам: сейчас они сгенерированы правилами.
- Больше карт с условиями: «Из укрытия», «В окружении», «По раненому» почти не используются.
- Закалка (условие растит число до конца боя).
- Отклик по событиям: «враг попал в капкан», «столкновение».

## 6. Словарь Наёмника и раскладка (квиз 2026-11-19)

Сначала словарь, потом раскладка по картам. Источник данных — `tools/descent_epiphanies.py`: в BASE сами карты,
в VARIANTS — 5 прозрений на карту. Запуск перезаписывает `cards.json` и `heroes.json` и печатает таблицу.

**Теги:** Удар, Шаг, Толчок, Защита, Шипы, Кровь, Клич.

**Новые условия:**
- Разгон N;
- Под щитом N;
- Сам ранен;
- Один на один;
- Спиной к стене (стена, препятствие или край);
- По оглушённому;
- По ослабленному;
- Цель со щитом.

**Отклик на события** (поле `echo.on`):

| Событие | Когда | Цель (`aim`) |
|---|---|---|
| `hit` | враг ударил вас | обидчик (`source`) |
| `near` | враг подошёл вплотную в свой ход | бьёт до его удара |
| `kill` | вы убили врага | — |

Карта с откликом на ход врага остаётся в руке на ход врага. Не сработала — уходит в сброс в начале вашего хода.

**Реакция** (`react`): карту нельзя сыграть самому, только откликом. Сработала — в сброс. Отклик копит
прозрение.

**Без простого применения:** в данных нет `alt`, на карте плашка «Без простого применения».

**Новые результаты:**

| Результат | Поле в данных | Что делает |
|---|---|---|
| Возврат | `main.back` | при условии карта после розыгрыша снова в руке |
| Следующая карта [Тег] | op `empower` | бонус урона первому удару следующей карты с тегом; тратится; гаснет в конце хода |
| Закалка | `temper {when?, n}` | после розыгрыша урон и защита карты +n до конца боя |

**Раскладка: базовое условие у карт**

| Элемент словаря | Карта |
|---|---|
| В окружении | Сшибка |
| Под щитом 10 | Удар телом |
| Сам ранен | Кровавый размах (без простого) |
| Разгон 4 | Натиск (оглушение) |
| Спиной к стене | Упереться |
| Один на один | Поединок |
| Цель со щитом | Пробить щит |
| По оглушённому | Добить лежачего |
| Закалка | Закалённый клинок |
| Возврат (Вслед за [Шаг]) | Отработанный приём |
| Следующая [Удар] | Подготовка |
| Кровь + Сам ранен | Кровавая клятва (без простого) |
| Под щитом 15 | Стена щитов |
| Реакции | Контрудар (получил удар), Настороже (враг вплотную), Трофей (убийство) |

Без простого применения: Боевой раж, Боевой клич, Инерция, Кровавый размах, Кровавая клятва и все реакции.

Остальные элементы словаря (По ослабленному, Из укрытия, Задел, Дважды, Печать с другими условиями, Возврат с
другими условиями) встречаются в вариантах прозрений. Прозрения наследуют базовое условие карты.

## Ключевые слова и состояния из CZN (квиз 2026-11-21)

Карты: `tools/descent_cards_czn.py` (17 Наёмнику, 17 Охотнице, 18 Пиромантке, у каждой 5 прозрений; только готовые
анимации навыков). Движок: `deck/battle.py` (power_fire, per_count, counter_strike, exhaust_card), тексты —
`deck/model.py` (power_text, per_text).

| Слово | Поле в данных | Что делает |
|---|---|---|
| Изгнание | `exhaust: true` / op `burn_card` | после розыгрыша карта уходит до конца боя; `burn_card` изгоняет N случайных карт из руки |
| Сохранение | `retain: true` | карта не сбрасывается в конце хода |
| Создать | op `add_card` (`card`, `cname`) | временные карты в руку (Метательный нож, Искра, Стрела), после розыгрыша — изгнание |
| Единственная | `unique: true` | в руке одна такая; вторая при доборе уходит под низ колоды |
| Сила до конца боя | `main.power` | карта не уходит в сброс; `on` (turn, play, step, kill, hit, exhaust, end) + `do`, `tag`, `aim`, `once`, или постоянное правило `mod` (burn_keep, bleed_keep, retain, counter_plus, counter_bleed) |
| «За каждую…» | `op.per: {what, k}` | +k к числу действия за каждое: played, tag:Тег, strength, bleed/burn/poison/vulnerable цели, exhausted, hand, counter, shield, heat, walked, foes_burning, foes_bleeding, foes, powers |

| Состояние | Что делает |
|---|---|
| Кровотечение (`bleed`) | в начале хода носителя — урон по стакам мимо защиты, затем стаков вдвое меньше |
| Контратака (`counter`) | стаки героя: враг ударил вплотную — ответный удар 4 (+Мощь), стак тратится |
| Мощь (`strength`) | +N к каждому удару до конца боя; `strength_x2` — удвоить |
| Уязвимость / Слабость | +50% получаемого / −25% наносимого урона, −1 в конце хода носителя |

Новые условия: «По уязвимому», «По кровоточащему». Новые теги: Создание, Изгнание; кровотечение — тег Кровь,
контратака — Шипы.

## Предметы (квиз 2026-11-21) — вместо даров богов

Как реликвии Slay the Spire: лежат в сумке весь забег и срабатывают только при редком условии — счётчики
(«каждая 10-я атака»), номер хода («каждый 5-й ход»), состояние хода («ход без атак, но с 3+ картами», «сыграна
1 карта или меньше»), HP ниже половины, последний враг, перетасовка колоды, изгнание, созданные карты, капкан,
контратака, свиток в статую. Данные — `tools/descent_items.py` → `data/deck/relics.json`, движок — `deck/items.py`
(события боя приходят из `deck/battle.py`).

- Источники: сундук на карте этажа (бывший алтарь) — 1 из 3; элита — 1 из 2; торговец — 2 на продажу; страж —
  1 из 3 «предметов стража»: +1 ресурс, но с минусом («Тина» в колоде, не больше 6 карт за ход, нет отдыха у
  костра, враги сильнее, −6 HP в начале боя, на карту меньше в награде; пирамида — рука не сбрасывается, но
  добор на 1 меньше).
- 61 предмет: 40 общих (22 обычных, 21 необычный, 11 редких — вместе с классовыми) и классовые: Наёмник 6
  (Разгон 5, кровосток, контратаки), Охотница 6 (Стрелы, капканы, выстрел издалека), Пиромантка 6 (перегрев,
  Искры, изгнание, горение), Жрец 3 (свитки в одну статую, осквернение, все статуи).
- Ресурс в тексте ({res}) — у героя свой: энергия, жар Пиромантки, свиток Жреца.
- Просмотр: значки под названием боя и на карте этажа (рамка по редкости, счётчик на значке, подсказка при
  наведении); сумка со всеми описаниями — I, клик по значкам или кнопка «Сумка» на карте этажа.
- Частота у бота (каждый предмет отдельно, 4 боя на героя): общие — не чаще ~1 раза за бой, классовые —
  только со своей сборкой.
