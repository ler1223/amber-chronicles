# «Сплав» — прототип мини-игры

Отдельная мини-игра: **шестиугольные соты 6×6**, рука цветных карт, силы
между картами, встречные слияния и бесконечный бой 1 на 1 с HP, намерениями и
пассивками врага.

## Запуск

```bash
python merge_duel.py
python merge_duel.py --seed 42
```

## Правила

- В руке 1–3 цвета: красный, жёлтый, синий.
- В начале забега генерируется матрица сил между цветами.
- Игрок выкладывает карты из руки на **свободные соты поля 6×6**.
- Уже выложенные карты **нельзя перемещать вручную**: они двигаются только
  автоматически в конце хода.
- **Space / «Разыграть карты»** запускает ход по этапам:
  1. **Выкладка** — вы размещаете карты на сотах.
  2. **Движение** — ровно одна итерация: каждая карта делает не больше
     одного шага по шести направлениям.
  3. **Слияние** — соседние карты с встречными намерениями и достаточной
     силой соединяются; это отдельная анимация.
  4. **Разыгрывание карт** — карты срабатывают по одной.
  5. **Ход врага**.
- Перед завершением хода на поле видны **следки**: пунктирные стрелки и
  полупрозрачные призраки сот показывают, куда сдвинется каждая карта.
  Соседние карты, готовые слиться, связываются золотой пунктирной линией.
- Сдвиг анимируется; после анимации применяются слияния, эффекты карт и ход
  врага.
- Влияние пары карт зависит от шестиугольного расстояния:
  `база = среднее по цветам + уровень первой + уровень второй`.
  Каждая сота пути уменьшает силу по модулю на 1 единицу; на большем
  расстоянии, чем запас силы, влияния нет.
- Карты сливаются **только если находятся в соседних сотах и обе намерены
  двигаться навстречу друг другу**, а сила на расстоянии 1 превышает число
  цветов старшей карты:
  - одноцветная — больше 1;
  - двухцветная — больше 2;
  - трёхцветная — больше 3.
- Просто стоять в соседних сотах недостаточно: если карты не намерены идти
  навстречу, слияния не будет.
- Слияние автоматическое и происходит после итерации движения.
- После движения карты разыгрываются **по одной**, а не одновременно:
  сверху вниз, затем слева направо. Срабатывание текущей карты
  подсвечивается на соте.
- Слияние проигрывается отдельной анимацией: две карты сходятся в одну
  с золотой вспышкой.
- Новая карта объединяет цвета, повышает уровень и сохраняет **обе исходные
  части** (их можно увидеть в подсказке при наведении на карту).
- У карты есть эффекты цвета: урон, защита, добор, горение, уязвимость.

## Управление

- **ЛКМ по карте в руке** — выбрать карту.
- **ЛКМ по пустой соте** — выложить выбранную карту.
- **Space / «Разыграть карты»** — запустить этапы: движение → слияния →
  разыгрывание карт → ход врага.
- **R** — новый забег.
- **Esc** — выход.

## Бой

Враги бесконечные: после победы начинается следующая волна, враг становится
сильнее. У врага есть:
- намерение: атака, защита или усиление;
- пассивка: регенерация, шипы, броня или ярость.

Красный цвет даёт урон, синий — защиту, жёлтый — карту. Комбинации добавляют
эффекты: горение, уязвимость и дополнительный добор.

## Ограничения прототипа

- Пока три цвета и бесконечные уровни без верхнего предела.
- Все карты на сотах срабатывают каждый ход; это первый вариант боевого цикла.
- Нет наград между волнами и сохранения — это следующий слой.
- Соты не очищаются между волнами; при полном заполнении можно продолжать
  ходы, пока слияния не освободят соседние соты.
