# «Сплав» — прототип мини-игры

Отдельная мини-игра без поля: рука из цветных карт, парные силы, автослияния
и бесконечный бой 1 на 1 с HP, намерениями и пассивками врага.

## Запуск

```bash
python merge_duel.py
python merge_duel.py --seed 42
```

## Правила

- В руке 1–3 цвета: красный, жёлтый, синий.
- В начале забега генерируется матрица сил между цветами.
- Сила между соседними картами — среднее значение пар цветов.
- Карта сливается, если сила больше **числа цветов старшей карты**:
  - одноцветная — больше 1;
  - двухцветная — больше 2;
  - трёхцветная — больше 3.
- Слияние автоматическое: в начале хода и после перестановки.
- Новая карта объединяет цвета и повышает уровень.
- У карты есть эффекты цвета: урон, защита, добор, горение, уязвимость, энергия.

## Управление

- **ЛКМ по карте** — сыграть карту.
- **Перетащить карту на соседнюю** — поменять их местами; после этого
  срабатывает автослияние.
- **Space / «Конец хода»** — ход врага.
- **R** — новый забег.
- **Esc** — выход.

## Бой

Враги бесконечные: после победы начинается следующая волна, враг становится
сильнее. У врага есть:
- намерение: атака, защита или усиление;
- пассивка: регенерация, шипы, броня или ярость.

Красный цвет даёт урон, синий — защиту, жёлтый — карту. Комбинации добавляют
эффекты: огонь, уязвимость, восстановление энергии.

## Ограничения прототипа

- Силы действуют только между соседними картами руки — иначе перестановка
  перестаёт иметь смысл.
- Пока три цвета и бесконечные уровни без верхнего предела.
- Нет наград между волнами и сохранения — это следующий слой.
