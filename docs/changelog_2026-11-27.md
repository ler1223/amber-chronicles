## 2. Карты и интерфейс

- Единая запись карт:
  - `^+2` / `^-1` — значок фей (прибавка/трата);
  - `За фею` / `За каждые N фей` — пассивный бонус;
  - `Порог N` — включение усиленной версии;
  - `Усиление` — сколько фей сжигается и что даёт.
- Длинный текст на карте обрезается с `…`.
- Постоянная плашка полного описания и всплывающее описание при наведении убраны.
- При **Shift** (или удержании карты) сбоку появляется окно «Полное описание» только если текст не помещается на лицо карты; для коротких карт ничего лишнего нет.
- Исправлено двоение текста при просмотре Shift: слой без текста больше не подменяет готовое лицо карты; под инспектор добавлена непрозрачная подложка.
- Прививка отображается за картой-хозяином: видно название; при розыгрыше хоста показывается короткая анимация срабатывания.
- Карты героев используют 128×128 спрайты из `assets/sprites/x4/`; модель героя в бою — масштаб 1.0.
- Широкая раскладка внедрена для карты, боя, колоды, наград, магазина, финала, аур и атласа.

## 3. Навигация и выход

- **Esc** на вложенных экранах работает как «назад»:
  - колода, торговец, атлас, стопки — возврат;
  - выбор стартовой колоды — к выбору героя;
  - награда — «Пропустить»;
  - выбор ауры — пауза.
- На карте этажа, выборе героя и финальном экране Esc открывает паузу.
- В паузе:
  - «Продолжить»;
  - «Выйти из забега» — сохранение удаляется, возврат к выбору героя;
  - «Выйти из игры».
- В бою Esc только закрывает чтение/снимает выбор; выйти из боя нельзя.
- Выход из игры корректно завершает цикл `descent.py`.
