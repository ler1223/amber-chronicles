# Аудит описаний способностей

Проверка выполнена по `data/skills.json`: искали сырые `HP`, `щит`, `урон`, `броня`, `AP`
в тексте и сверяли с эффектами.

## Что сделано

- Сырые `HP`, `щит` и `урон` в описаниях переведены в проценты от базовой атаки/HP.
- Для HP-затрат добавлен `hp_cost_pct`: цена теперь считается от максимума HP.
- Для лечения по времени добавлен `regen_pct`: регенерация считается от максимума HP.
- Для «Отдать силы» добавлен `cost_pct`, для «Перерезать нити» — `heal_pct`.
- Ловушки `snare`/`bear_trap` получили процентный урон от атаки владельца.
- Описания обновлены: `taunt`, `shield_charge`, `consecrate`, `spirit_link`, `serenade`,
  `blood_*`, `tether`, `soul_web`, `cut_threads` и другие.

## Что осталось фиксированным

Остались только **броня, AP, длительности и специальные эффекты** — это не скейл от
характеристик, а ресурсы/плоские параметры:

- `+3 брони`, `+5 брони` — плоская броня;
- `+2 AP`, `3 AP` — ресурс AP;
- `1 сек`, `5 сек` — длительности;
- `trance`: «+1% урона за 1 HP лечения» — специальная механика превращения лечения;
- отдельные легаси-мелодии барда и вражеские `e_*`-эффекты, которые не входят в пулы героев.

Новые классы (Страж, Шаман, Бард) используют проценты для скейла; сырые `AP`, `броня`
и длительности — это не скейл, а ресурсы/плоские эффекты.
