# «Спуск»: CZN-тактическая волна

## Что взято из CZN

CZN — карточная игра, но её теги хорошо ложатся на клеточное поле, если перевести их в **позицию,
область и сдвиг**. В этой волне взяты не все теги, а четыре рабочих:

| CZN | «Спуск» | Смысл на поле |
|---|---|---|
| Commence the Hunt | **Преследование** | одноцелевые атаки получают дополнительный выстрел по той же цели |
| Area / AoE | **Область** | карта бьёт по клетке/нескольким врагам |
| Retain | **Сохранение** | карта остаётся в руке в конце хода |
| Exhaust | **Изгнание** | карта уходит из боя |
| Push / Collision | **Толчок** | сдвиг врага, столкновения, стены и края |
| Movement | **Шаг** | reposition, заходы и дистанция |

`Комбо`, `Метка`, `Резонанс` и `Цепочка` уже были в игре и остаются основой.

## Преследование

- `ds["hunt"]` — запас преследования, до 5.
- Карта с тегом `[Преследование]` после **одноцелевой атаки** делает дополнительный выстрел на величину запаса
  по той же цели. Это происходит один раз за карту и тоже расходует метку.
- `h_stalk` («Преследование») даёт +2 преследования; `h_hunt` («Охотничий азарт») — +1 при игре `[Выстрела]`.
- Пейофф `h_hunt_final` («Завершение гона») считает `per hunt`.
- Предмет «Рог гона» даёт `[Преследование]` +2 урона и +1 преследование за первую такую карту в ход.

**Игра:** сначала накопить преследование, затем бить одноцелевыми выстрелами. AoE преследование не запускает —
нужно выбрать одну цель. Движение помогает держать дистанцию и не давать врагам сомкнуться.

## Школы

### Охотница: mark + Преследование («Гон»)

- Старт: `h_marking` ×2, `h_mark_burst`, `h_beat`, `h_stalk`, `h_shot` ×2, `h_dodge` ×2, `h_trail`, `h_net`.
- Двигатели: `h_stalk` (преследование), `h_hunt` (преследование при выстрелах), `h_marking` (метки).
- Пейоффы: `h_beat` (загон + метка), `h_mark_hunt` (урон за метки), `h_hunt_final` (урон за преследование).
- Область: `h_area_hunt` — веерный обстрел с метками; хорош против групп, но не запускает преследование.
- Не-атаки, поднятые Цепочкой, не разыгрываются вслепую: «Ложный след» и подобные карты ждут,
  пока игрок выберет клетку/область/цель.
- Порядок: `h_stalk`/`h_hunt` → `h_beat` / `h_mark_hunt` → `h_hunt_final`; метки ставить до пейоффа.

### Наёмник: «Натиск»

- Пассивка: толчок даёт +1 Разгон; столкновения наносят +2.
- Старт: `strike` ×3, `defend` ×2, `lunge_rush` ×2, `shield_ram` ×2, `sweep`, `m_bulldoze`, `m_ring`.
- Двигатели: `m_bulldoze` (подход + толчок), `m_grapple` (притянуть), `m_break` (прорыв), `lunge_rush`.
- Область: `m_ring` (все соседние), `m_quake` (радиус 1).
- Пейофф: столкновения у стены, `sweep` при окружении, `m_break` при Разгоне.
- Порядок: подойти/притянуть → встать так, чтобы за врагом была стена/край → толкнуть → добить область.
- Главное: **не бить в пустоту**. Толчок без стены — это позиция; толчок в стену — это урон.

### Пиромантка: «Пепел»

- Пассивка: `[Область]` наносит +2 урона.
- Старт: `p_bolt` ×3, `p_ward` ×2, `p_stride` ×2, `p_fireball`, `p_grenade`, `p_oil`, `p_ashstep`.
- Двигатели: `p_grenade`, `p_oil`, `p_fireball`, `p_geyser`, `p_fire_rain`.
- Пейофф: `p_meteor`, `p_sun`, `p_keg`, `p_chain`.
- Позиция: `p_stride`/`p_ashstep` — выйти из строя, поставить зону так, чтобы враги шли через огонь.
- Порядок: `p_oil`/`p_grenade` → `p_fire_rain`/`p_geyser` → `p_meteor`; не тратить область на одного врага.

## Что проверять в игре

- Преследование: карта с `[Преследование]` должна давать **второй выстрел** только по одной цели; по области — нет.
- Натиск: толчок в стену должен наносить больше, чем толчок в пустоту; толчок даёт Разгон.
- Пепел: `[Область]` должна бить на 2 сильнее; на нескольких врагах это заметнее.
- Колоды: Draw/Used/Discard — см. `docs/descent_deck_piles.md`.

## Следующие шаги

- Проверить, не стали ли `m_ring` и `m_quake` слишком сильны в окружении.
- Добавить Жрецу позиционную область через статуи (свиток-сдвиг/зона).
- Если Преследование окажется слабой — добавить ещё один источник запаса, а не повышать цифры.
- Не добавлять новые теги, пока у этих нет 3–5 двигателей и 2 пейоффов.
