# Охотница: карты Tressa-стиля и поддержка

## Что перенесено из CZN (Tressa)

Tressa строит игру вокруг временных **Shadow Dagger**, **Agony** и перезарядки. В «Спуске» они
заменены существующими ресурсами, без копирования названий и дублирования механик:

| CZN | «Спуск» |
|---|---|
| Shadow Dagger | временная **Кровавая стрела** (`arrow_blood`): 0 стоимости, 3 урона и кровотечение 2, изгоняется |
| Agony | **кровотечение** (уже есть как DoT) |
| Curse | сила **«Кровавый навет»**: при игре `[Выстрела]` цель получает кровотечение |
| Vital Attack | **«Кровавый залп»**: три удара, по кровоточащей цели каждый удар сильнее |
| Shadow Reload | **«Перезарядка тьмы»** и **«Второе дыхание»**: добор, энергия и стрелы |
| Retain | **«Терпеливый выстрел»** остаётся в руке |
| Discard/Exhaust-манипуляции | **«Теневой колчан»** создаёт стрелы; **«Разведка»** и **«Второе дыхание»** крутят колоду |

Похожие старые карты не удалялись: `h_jagged`, `h_poison`, `h_rain`, `h_toxic`, `h_focus`, `h_arrow_well`
остаются, но новые карты занимают другие роли.

## Новые карты

| Карта | Роль |
|---|---|
| `h_bloodlust` «Кровавый азарт» | +2 силы, −2 HP, добрать карту: прямой бафф урона |
| `h_blood_rite` «Кровавый навет» | сила: каждый `[Выстрел]` вешает кровотечение |
| `h_blood_volley` «Кровавый залп» | три удара; по кровоточащей цели бонус к каждому удару |
| `h_shadow_quiver` «Теневой колчан» | две кровавые стрелы и добор |
| `h_dark_reload` «Перезарядка тьмы» | добор 2, +1 энергия, кровавая стрела |
| `h_second_wind` «Второе дыхание» | 0 стоимости: +1 энергия, добор 1, изгнание |
| `h_scout` «Разведка» | добор 2 без прямого урона |
| `h_smoke_screen` «Дымовая завеса» | область: слабость 2 и добор |
| `h_snare_net` «Облава» | область: корни и метка |
| `h_patient_shot` «Терпеливый выстрел» | атака с сохранением в руке |

## Колоды

### mark — «Кровавый гон»
- Новое ядро: `h_bloodlust` → `h_blood_rite` → `h_blood_volley` / `h_beat` / `h_hunt_final`.
- `h_shadow_quiver` даёт временные стрелы для добора и кровотечения.
- `h_patient_shot` можно держать в руке и разыграть в нужный ход.

### quiver — «Тёмный колчан»
- `h_shadow_quiver` и `h_dark_reload` создают кровавые стрелы.
- `h_second_wind`, `h_scout`, `h_dark_reload` дают добор/энергию.
- `h_smoke_screen`, `h_snare_net` — области для контроля, а не только урон.

### Общее
- Кровавые стрелы — временные: после розыгрыша изгоняются, колода не засоряется.
- Кровотечение — существующий DoT; отдельного тега Agony нет.
- `[Кровь]` усиливает новые карты предметом «Алый клинок», `[Область]` — «Печатью области».
