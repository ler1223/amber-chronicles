# Архив: режимы вне основной игры

Основная игра — `python main.py` (Экспедиция и Бесконечный забег). Всё здесь **не поддерживается**: не проверяется тестами
(`pytest.ini` смотрит только в `tests/`) и не правится вместе с механиками. Могут не запускаться после переделок
героев (2026-11-10: навыки в процентах от статов, новые лучник, подрывник, шаман).

| Что | Файлы |
|---|---|
| Старые режимы: игра на карте биома, режим героев, сюжет, песочница боёв | `legacy.py`, тесты `tests/test_app.py`, `test_run.py`, `test_profile.py`, `test_squad.py`, `test_story.py` |
| Обучение нейросетей в игре | `learn.py` |
| Лаборатория нейросетей (PPO, планировщик, испытания) | `lab.py`, `game/lab_scene.py`, `sim/nn_lab.py`, `sim/full_obs.py`, `sim/trials.py`, `tools/train_schools.py`, `tools/trials.py`, `docs/neural_lab.md`, тесты `tests/test_neural*.py` |
| Старые данные: удалённые навыки/ветки и one-hero конфиг «одиночки» | `legacy_data/` |
| Старые генераторы контента (друид/ассасин до переработки, rework-скрипты) | `tools/content_*` |

Код, который всё ещё нужен основной игре (сцены старых режимов внутри `game/app.py`, `sim/neural.py` и т. п.),
остался на месте — его просто больше не трогаем ради старых режимов. Запускать отсюда: `python archive/legacy.py`
из корня проекта (пути могут потребовать правки).
