# Старые генераторы контента

Эти скрипты больше не участвуют в запуске игры и оставлены только как исторический источник данных:

- `content_heroes.py`
- `content_rework1.py`
- `content_rework2.py`
- `content_rework3.py`
- `content_items.py`
- `content_chapters.py`
- `content_vfx.py`

Они могут перезаписывать `data/*.json` старыми определениями (в частности, старыми друидом и ассасином). Не запускать без отдельной проверки и резервной копии данных.
