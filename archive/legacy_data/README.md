# Старые данные

Сюда вынесено то, что больше не участвует в загрузке основной игры:

- `skills_legacy.json` — 15 старых навыков, которые не ссылаются ни классы, ни сюжетные пулы, ни враги, ни предметы/таланты.
- `branches_legacy.json` — их ветки.
- `vfx_skills_legacy.json` — старые записи VFX для удалённых навыков.
- `expedition_solo_legacy.json` — старый конфиг режима «Одиночка» на одного героя (keep/boss_keep/hero_mods/slot_levels/zoom).

Текущие `data/skills.json`, `data/branches.json` и `data/expedition.json` этих записей не содержат.

Важно: `sacrifice` — действующий навык жреца, он оставлен в основной игре и в архив не входит.
