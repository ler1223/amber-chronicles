# Грань — ювелирная мастерская

Маленькая отдельная игра в духе Potion Craft, но про огранку камней. Главное в ней —
**рост понимания самого игрока**: среди невзрачных кусков сырья научиться видеть
будущий камень, прочитать его фонариком и сделать из него то, что задумал.

## Запуск

```
python gem_workshop/main.py      # из корня репозитория
cd gem_workshop && python main.py  # или из папки проекта
```

Игра запускается в полноэкранном режиме; `F11` или `Alt+Enter` — окно/полный экран.
Интерфейс рисуется в 1280×800 и масштабируется под монитор. Проект самостоятельный:
всё нужное лежит внутри `gem_workshop/`. Сохранение — `gem_workshop/save/workshop.json`.

## Цикл игры

1. **Ученичество (дни 1–3).** Мастер даёт камни с известным ответом: прочитать камень,
   открыть окошко и распилить по перу, купить первую партию. Аренду платит он.
   Потом уходит на покой — остаётся шкаф «Образцы мастера» с ответами.
2. **Закупка — только мешочками.** 2–4 смешанные партии по 5–8 кусков. Высыпать на
   стол, осмотреть каждый кусок; цена — по виду (масса, форма, цвет), что внутри —
   продавец не знает. Хорошее нутро под плохой коркой — заработок.
3. **Осмотр и метки.** Фонарик сзади (просвет), прямой и боковой (тёмное поле).
   Метки — свой прогноз: перо, отпечаток, облако, шёлк, кристалл, полость, цвет, чисто.
   Правды в тексте нет: её показывает только сам камень.
4. **Свой камень:** окошко (полированная площадка, сквозь неё видно без корки),
   пила (распилить по трещине на два куска), скупщик — за бесценок.
5. **Разметка** по своим меткам: яркие останутся в камне, тусклые уйдут в отход;
   чистота, риск и цена — по вашей оценке.
6. **Обдирка** на грубом круге: кусок (с коркой, налётом, породой) стачивается до
   золотого контура будущего камня; за контур — потеря массы, у трещины — скол.
7. **Огранка** на станке: угол, индекс, подача, диски; грань за гранью вспыхивает
   полировкой.
8. **Результат:** «было → стало» (кусок рядом с камнем, масса, выход, цена покупки),
   разбор меток (верно / не то / ложная / пропущено), продажа клиенту или на витрину.

## Что есть в рендере

- Трассировка выпуклого многогранника на видеокарте: Френель, полное внутреннее
  отражение, дисперсия, поглощение на миллиметр, плеохроизм, двупреломление.
- Сырьё разное: обломки, пластинки, щепки, кристаллы в породе (мрамор, пегматит,
  тёмная порода, агатовая корка), окатыши, редкие целые кристаллы. Старые изломы
  матовые, свежие сколы раковистые, грани призмы со штриховкой, ржавый налёт.
- Включения по атласу: перо (зеркало полного отражения, радужность), отпечаток,
  облако, шёлк, кристаллик-многогранник с ореолом, полость с всплывающим
  пузырьком, белые зоны. Светлое и тёмное поле дают противоположную картину.
- Зоны роста по граням кристалла — одной формулой в шейдере и в оценке цены.

## Управление

- Мышь — карточки и кнопки.
- Осмотр: `ЛКМ` — вращать, колесо — приблизить, `F` — фонарик, `1/2/3` — сзади/прямой/боковой,
  `ПКМ` — поставить метку выбранного типа (по метке — убрать), окошко и пила — `ПКМ`
  при выбранном инструменте; на столе — клик по куску или стрелки.
- Разметка: `ЛКМ` — камень, `ПКМ` — контур, `СКМ` — камера, `Q/E` — крен, `WASD` — сдвиг,
  колесо — размер, `Enter` — на обдирку.
- Обдирка: `ЛКМ` — повернуть кусок, `Пробел` — прижать к кругу, `Shift` — бережно,
  `Enter` — на станок.
- Огранка: `1–9` — огранка, `W/S` — угол, `A/D` — индекс, `Пробел` — к диску,
  `Enter` — грань готова, `F` — перевернуть, `J` — диагностика, `Tab` — осмотр.
- `Esc` — назад (на станке после обдирки — завершить работу).
