# Правила работы с файлами

- **Всегда** отдавай предпочтение встроенным инструментам `Grep` и `Read` для поиска и чтения файлов.
- **Никогда** не используй громоздкие shell-скрипты (например, на Python) для чтения или поиска по файлам, если задачу можно решить с помощью `Grep` и `Read`.
- Для независимых задач (например, поиск в нескольких файлах) используй параллельные вызовы инструментов в одном сообщении.
- Если задача сложная и многосоставная, используй инструмент `task` для запуска сабагентов.
