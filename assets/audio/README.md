## Где играет

- **Меню и выбор героя** — `menu_mythica`, `menu_doodle`;
- **болото** — `forest_ambience`, `alone`;
- **подземелье** — `dungeon_ambience`, `narrow_corridors`, `cave_explorer`;
- **кузни** — `portal`, `crystal_cave`;
- **бой** — `battle_theme_a`, `battle_random`;
- **босс** — `battle_theme_a`, `war_boss`, `battle_random`;
- **костёр и награды** — `tavern_grog`, `forest_ambience`;
- **магазин** — `tavern_grog`, `menu_doodle`;
- **финал** — `alone`.

При смене локации трек меняется; при возвращении в ту же локацию выбирается другой трек из её набора.
