# Фоновая музыка

## Outer Space Loop

- Автор: **wipics**
- Источник: <https://opengameart.org/content/outer-space-loop>
- Лицензия: **CC0 1.0 Universal (Public Domain)**
- Оригинальный файл: `outer_space.mp3` (страница источника)
- В игре: `outer_space_loop.ogg` — тот же трек, перекодирован из MP3 в Ogg Vorbis для циклического
  воспроизведения в pygame.

CC0 не требует указания автора, но источник сохранён здесь, чтобы было понятно происхождение файла.
Трек используется как спокойный фон в «Спуске» и «Хрониках янтаря».

Громкость: **F10** — панель звука; также настройка «Громкость музыки» в общем меню настроек.
